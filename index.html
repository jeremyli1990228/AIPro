返回 JSON 示例:{"offline":[{"building":"A栋","name":"空调机组 #1","type":"暖通"}],"total_offline":5}
返回 JSON 示例:{"name":"智慧产业园","area":"8.6万㎡","buildings":6,"enterprises":42,"people":2800}
